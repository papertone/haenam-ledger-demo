# 해남농원 주문장부 (시연)

절임배추 농원이 쓰던 엑셀 주문 장부를 손님 명단으로 바꾸고, 단골에게 안내 문자를 보내는 흐름을 보여 주는 시연 화면입니다.

- 오늘: 올해 주문 현황, 작년 손님 중 아직 소식 없는 분
- 주문 적기: 전화번호로 단골 자동 채우기, 카톡 주문 붙여넣기 정리
- 장부: 2024년부터 받은 주문 검색, 엑셀로 복사
- 손님: 단골, 작년 손님 올해 아직 같은 묶음
- 안내 보내기: 문자 동의한 분께만 가는 안내 문자

농원 이름, 손님, 주문, 가격은 모두 가상의 예시 데이터입니다. 실제 문자는 발송되지 않고, 새로 입력한 주문은 새로고침하면 사라집니다.
