# 해남농원 주문장부 (시연)

절임배추 농원이 쓰던 엑셀 주문 장부를 손님 명단으로 바꾸고, 단골에게 안내 문자를 보내고, 택배 배송까지 확인하는 흐름을 보여 주는 시연 화면입니다.

시연 주소: https://papertone.github.io/haenam-ledger-demo/

- 오늘: 올해 주문 현황, 작년 손님 중 아직 소식 없는 분
- 주문 적기: 전화번호로 단골 자동 채우기, 카톡 주문 붙여넣기 정리
- 장부: 2024년부터 받은 주문 검색, 엑셀로 복사
- 배송: 송장번호로 배송 조회, 배송 중인 주문 한 번에 조회, 송장 적고 손님께 배송 안내
- 손님: 단골, 작년 손님 올해 아직 같은 묶음
- 안내 보내기: 문자 동의한 분께만 가는 안내 문자

농원 이름, 손님, 주문, 송장번호, 가격은 모두 가상의 예시 데이터입니다. 실제 문자는 발송되지 않고, 새로 입력한 내용은 새로고침하면 사라집니다.

## 택배 조회

배송 화면은 [딜리버리API](https://www.deliveryapi.co.kr/docs)의 `POST /tracking/trace` 요청과 응답 형식을 그대로 따릅니다. "개발자 보기"를 열면 실제로 오가는 요청과 응답 JSON을 볼 수 있습니다.

기본은 **시연 모드**입니다. 실제 API 대신 같은 모양의 예시 응답을 페이지 안에서 만들어 보여 줍니다. 장부에 있는 송장만 조회됩니다.

### 실제 조회로 바꾸기

딜리버리API의 Secret Key는 브라우저에 노출하면 안 됩니다. 그래서 키를 숨겨 주는 작은 서버를 하나 거칩니다.

1. 딜리버리API에서 API Key와 Secret Key를 발급받습니다. 신규 가입자는 무료 요금제가 없어서 유료 요금제가 필요합니다.
2. Cloudflare Workers(무료)에 `worker/tracking-proxy.js`를 올립니다.
3. Worker 설정에서 `DELIVERY_API_KEY`, `DELIVERY_SECRET_KEY`를 Secret으로, `ALLOWED_ORIGIN`을 `https://papertone.github.io`로 넣습니다.
4. `index.html`에서 `const TRACKING_PROXY = '';`에 Worker 주소를 넣습니다.

공개 페이지에 실제 키를 연결하면 누구나 조회 한도를 쓸 수 있습니다. 시연할 때만 켜 두는 것을 권합니다.
